# Double9 Ventures

Responsive, buildless five-page website. Open `dist/index.html` or serve `dist/` with any static web server. No package installation or API keys required.

## Deployment
Vercel: Framework Other, no build command, output directory `dist`.
Hostinger: upload the contents of `dist` to `public_html`.

## Pages and features
Home, About, Our Vision, Partnerships, Our Team. Animated projected DNA helix with pause control and reduced-motion support. Keyboard-accessible native dialog portrait lightboxes; mobile menu; page-specific SEO titles and descriptions.

## Assets
`dist/assets.js` contains embedded JPEG data URLs extracted from supplied logo and leadership slides so the site is portable and requires no external image host. Original faces are retained. Subtle non-destructive SVG sharpening and CSS contrast improve display; source resolution limits enlargement quality.

## Content
About copy supplied by the owner. Leadership and partner biographies adapted from supplied slides. Certification is described as a development goal, not an achieved credential. No contact address was supplied; the website does not invent one or simulate a working contact form. Add a verified company email/contact workflow before a public launch if desired.

## Verification
HTML structure, internal links, asset references, metadata, and JS syntax checked locally. Browser/device verification should be performed before public launch.
